# Design system
Dark, minimal, modern tech; original typography-led editorial composition. No gradients, neon, glows, glassmorphism, excessive pills or ubiquitous cards. Geist Sans for headings, copy, buttons and nav; Geist Mono selectively for section numbers, dates, tech metadata. Self-host fonts. Weights 400 body, 500 controls, 600 headings, 700 hero emphasis.

Pixels. Palette: background #0A0A0A; secondary #111111; surface #171717; hover #1F1F1F; inverse #FAFAFA. Primary text #FAFAFA; secondary #A3A3A3; muted #808080; disabled #525252; inverse #0A0A0A. Borders subtle #262626, default #404040, hover #737373, focus #D4D4D4. Ensure readable contrast; disabled color only for disabled elements. 1px borders, 4–8px radius, minimal shadows. Lucide stroke 1.5; sizes inline 16, button 18, standard 24, featured 32. Brand logos monochrome even on hover. Tech tiles: 32px logos, labels Geist Sans 14 (fit responsively), background #111111, hover #171717, border #262626 to #737373, radius 6px; logos #A3A3A3 to #FAFAFA. Use consistent spacing and fluid containers; proposed initial breakpoints 768 and 1024px, verify visually. Touch targets at least 44px. Project imagery can show original colors on mobile; desktop grayscale to color on hover. No other colored UI.
