# Motion specifications
Approved eight patterns: staggered fade-up 600ms/80ms; underline reveal and link text colour 400ms ease-in-out; copy feedback 150ms with 1.5s reset; menu transformation 300ms; tooltip reveal 150ms with 200ms hover delay; slide transition 400ms; line expansion 600ms; staggered elements 400ms/80ms. Tokens instant 100, fast 150, normal 250, moderate 400, slow 600ms. Entrance easing cubic-bezier(.22,1,.36,1); standard ease-in-out. Use Motion for entrance and layout transitions, CSS for underline and line expansion, React state for menu/copy, shadcn tooltip. Trigger viewport entrances once; do not delay critical hero content rendering. Respect prefers-reduced-motion: no continuous animation, no parallax, native cursor, immediate transitions and readable static content. Mobile accordion 400ms height transition, plus/minus animation, stagger 80ms. Mobile experience timeline line expands on entry (600ms) then responsibilities reveal. Desktop project preview switches 400ms, arrow 250ms, underline and link text colour 400ms ease-in-out, image filter 400ms. Avoid animation conflicts and layout shifts.

Technology Stack tiles fade up once per category on viewport entry, with a 400ms duration and an 80ms stagger. Tile colours change over 250ms with ease-in-out. Category dividers use the 600ms line expansion. Tooltips use a 200ms hover delay and a 150ms reveal. Reduced motion shows tiles immediately and disables these visual transitions.

Work Experience content reveals once on section entry with a 600ms fade-up and 80ms stagger. Dividers expand over 600ms. Reduced motion keeps all experience content immediately visible.

Hero network: every connection carries an elapsed-time packet with its own phase and slight speed variation. Packets follow the projected endpoints and fade at both ends of their travel. Reduced motion keeps the network static.

Phase 03C network interactions and native SVG rendering use a shared frame loop. Magnetic displacement is bounded to 7px, hover scale targets 1.14, and cursor ring and emphasis transitions use 250ms. The 6px cursor becomes smaller over a node, while a separate 6px orbit dot takes 2500ms per revolution. Pointer parallax is depth dependent and bounded. A hovered node reveals its tooltip after 200ms with a 150ms reveal. Touch and keyboard selection reveal the description directly. Reduced motion suppresses ambient motion, cursor effects, and parallax.

Phase 03D ambient particles drift diagonally at 45 degrees with elapsed-time movement. Three depth layers vary size, speed, and opacity independently, with occasional short streaks in the foreground. Particles recycle beyond the viewport so they enter from the top or left. The shared frame loop pauses when the document is hidden and resets its timestamp on resume. Reduced motion disables drift, opacity variation, and the continuous loop while allowing a static redraw on resize.
