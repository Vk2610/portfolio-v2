# Hero network
Canvas 2D with projected depth (2.5D), no Three.js. Transparent canvas without visible frame. 22 nodes from the shared technology catalog with local monochrome SVGs. Large primary (2): React, Node.js. Medium core (10): JavaScript, TypeScript, Express.js, MongoDB, MySQL, Tailwind CSS, GitHub, Vercel, Python, PostgreSQL. Small supporting (10): HTML5, CSS3, Bootstrap, Next.js, Pandas, Firebase, Git, VS Code, Postman, Figma. All 22 nodes appear on desktop and mobile in one connected graph of meaningful relationships, with no self-connections, repeated edges, or isolated nodes. Use an organic semi-mesh with approximately 34–36 meaningful unique connections. Base network spread is 92.5%, horizontal expansion is 1.275 independently of base spread, vertical spread is increased by 12.5%, depth intensity is 67.5%, and connection visibility is 67.5%. Desktop Hero columns allocate approximately 40% to text and 60% to the network. Keep at least 20px node clearance on desktop and adapt clearance for mobile. Primary nodes are reduced by 10%, with core and supporting sizes preserved. Foreground, midground, and background use subtle opacity, border, and floating-speed differences. Desktop node diameters are 76–88px primary, 48–56px core and 36–42px supporting, with independently adapted mobile sizing. Every edge carries a continuously travelling, elapsed-time-based packet with an independent phase and slight speed variation. Packets follow current projected endpoints, fade at either end, and are disabled for reduced motion. Depth affects size, opacity and parallax.
