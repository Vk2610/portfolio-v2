# Hero network
Native SVG with projected depth (2.5D) and a transparent background. 22 nodes from the shared technology catalog with local monochrome SVGs. Large primary (2): React, Node.js. Medium core (10): JavaScript, TypeScript, Express.js, MongoDB, MySQL, Tailwind CSS, GitHub, Vercel, Python, PostgreSQL. Small supporting (10): HTML5, CSS3, Bootstrap, Next.js, Pandas, Firebase, Git, VS Code, Postman, Figma. All 22 nodes appear on desktop and mobile in one connected graph of meaningful relationships, with no self-connections, repeated edges, or isolated nodes. The approved semi-mesh has 35 unique connections. Base network spread is 92.5%, horizontal expansion is 1.275 independently of base spread, vertical spread is increased by 12.5%, depth intensity is 67.5%, and connection visibility is 67.5%. Desktop Hero columns allocate approximately 40% to text and 60% to the network. Keep at least 20px node clearance on desktop and adapt clearance for mobile. Primary nodes are reduced by 10%, with core and supporting sizes preserved. Foreground, midground, and background use subtle opacity, border, and floating-speed differences. Desktop node diameters are 68.4–79.2px primary, 48–56px core and 36–42px supporting, with independently adapted mobile sizing. Every edge carries a continuously travelling, elapsed-time-based packet with an independent phase and slight speed variation. Packets follow current projected endpoints, fade at either end, and are disabled for reduced motion. Depth affects size, opacity and parallax. The viewBox follows the container in CSS pixels, and pointer positions use the inverse SVG screen transform. The renderer caches local SVG markup and mounts native paths, circles and lines once. A shared animation frame loop updates their positions and opacities and pauses offscreen or when the document is hidden. Unavailable logos use fallback labels. Avoid per-frame React updates.

State: base position + drag offset + parallax + float. On pointer down hit-test nodes, store grab offset and capture pointer, freeze relevant parallax and floating during drag so node tracks finger/pointer directly. Release retains new position and resumes float/parallax smoothly without jumping. Clamp within the SVG bounds. Handle pointercancel. Touch drag on nodes only; allow vertical scrolling elsewhere. Tap selects node, shows purpose tooltip; tap elsewhere dismisses. Keyboard-accessible equivalent list/controls for interactive network, all technologies also visible in stack.

Hover: nearest node magnetic offset max 7px, scale 1.14; connected edges brighten, unrelated nodes dim to 32% of default opacity. Tooltip name + purpose delay 200ms. Orbital cursor only within network on fine-pointer devices: white pointer dot ~6px diameter, smaller over node; ring 1px stroke at node radius + 8px, 6px orbit dot rotating once per 2.5s; 250ms transition. No inverted/blend cursor. Native cursor outside and on touch/reduced motion. Maintain drag behavior when adding cursor. Test hover, dragging, release, resize, touch scroll, reduced motion, leaving the network and keyboard.

Phase 03C uses positioned DOM buttons for keyboard exploration and touch gesture boundaries. Pointer capture preserves the grab offset throughout a drag, while persistent offsets survive SVG resizing. Touch interaction starts on a node with a 6px movement threshold; empty network space allows page scrolling. Reduced motion keeps the native cursor and supports selection and direct manipulation.

Node descriptions are available to assistive technology and shown in a single viewport-aware tooltip. The tooltip is suppressed during a drag. Dragged nodes, their neighbours, and their connecting packets share the same projected positions.
