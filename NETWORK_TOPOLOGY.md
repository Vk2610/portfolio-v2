# Hero network
Canvas 2D with projected depth (2.5D), no Three.js. Transparent canvas without visible frame. 20 nodes with local monochrome SVGs, React and Node.js larger central nodes. Medium core JS, TS, Express, MongoDB, MySQL, Tailwind, GitHub, Vercel. Smaller HTML5, CSS3, Bootstrap, shadcn/ui, Python, Firebase, Git, VS Code, Postman, Figma. Meaningful relationships (frontend, backend, data, tooling), subtle floating and data packets along edges; no random full graph. Depth affects size, opacity and parallax. Resize with container, cap DPR if necessary; keep nodes within bounds. Preload images, handle fallback labels, pause animation offscreen, cleanup RAF/listeners. Avoid per-frame React updates.

State: base position + drag offset + parallax + float. On pointer down hit-test nodes, store grab offset and capture pointer, freeze relevant parallax and floating during drag so node tracks finger/pointer directly. Release retains new position and resumes float/parallax smoothly without jumping. Clamp within canvas. Handle pointercancel. Touch drag on nodes only; allow vertical scrolling elsewhere. Tap selects node, shows purpose tooltip; tap elsewhere dismisses. Keyboard-accessible equivalent list/controls for interactive canvas, all technologies also visible in stack.

Hover: nearest node magnetic offset max 7px, scale 1.14; connected edges brighten, unrelated nodes dim to 32% of default opacity. Tooltip name + purpose delay 200ms. Orbital cursor only within network on fine-pointer devices: white pointer dot ~6px diameter, smaller over node; ring 1px stroke at node radius + 8px, 6px orbit dot rotating once per 2.5s; 250ms transition. No inverted/blend cursor. Native cursor outside and on touch/reduced motion. Maintain drag behavior when adding cursor. Test hover, dragging, release, resize, touch scroll, reduced motion, leaving canvas and keyboard.
