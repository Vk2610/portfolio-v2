# Product specification
Single-page full stack developer portfolio. Sections: Navbar, Hero, Professional Status, About, Technology Stack, Work Experience, Selected Projects, Contact, Footer. Anchor IDs about, stack, experience, work, contact. No React Router required. Reference Figma https://www.figma.com/design/3zoCvoNfXB3pM53LMczYHN (desktop 1:2, mobile 1:87); it is not fully visually verified and lacks final mobile experience/projects. Written requirements override it.

Navbar horizontal desktop, animated hamburger mobile. Hero desktop split typography and network; mobile stacked typography, CTA then network; preserve all 20 nodes. No custom cursor outside network. Professional Status and About retain existing design. No invented employment availability. Technology Stack categorized grid on desktop, compact three-column grid on mobile, no tabs. All 20 logos visible; actual local Simple Icons/official SVGs, not generic initials.

Experience desktop: editorial two columns, dates/location/type left; role/company/responsibilities/technologies right, expanding divider and staggered fade-up. Mobile: animated vertical career timeline, date marker, role/company/location, responsibilities and technologies revealed as section enters viewport. No duplicated experience announced by screen readers.

Projects desktop: interactive index with four numbered rows left and image/details right. First selected initially; hover or keyboard focus previews; click retains selection. Define pointer leave to restore selected project if temporarily previewing another. Active white text/divider; inactive gray; fade + slide switching; arrow movement; animated underline links. Mobile: single-open collapsible accordion, first expanded by default; tap header to toggle, plus-to-minus, actual screenshot, description, technology list, valid links inside. 400ms expansion, staggered fade-up, original screenshot colors on mobile. Use shadcn accordion primitives, custom styles. No swipe carousel or sheet. Preserve other sections.

Contact: existing stacked responsive form and direct email/social actions; mailto draft plus copy email with feedback, no fake success, backend optional only with approval. Footer compact responsive typography, back-to-top. Add semantic metadata, social preview, sitemap, robots; use actual deployment URL once available. Respect reduced motion, focus, keyboard and touch. No scroll hijacking or loader.

Stack: React TS Vite Tailwind v4 shadcn/ui Motion Canvas 2D Lucide React local SVGs local Geist. No Redux, Zustand, router, database, auth, CMS, GSAP, Three.js, Next.js or Express for this site. Use Node LTS, npm lockfile, ESLint, Prettier, Vitest, Playwright. Pin resolved dependency versions after setup; do not assume current versions. New repo only, existing site untouched.
